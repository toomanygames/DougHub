Install the app with SmartScreen on

You do not need to turn anything off. SmartScreen asks you to confirm new programs, and this guide shows each screen and which button to press.

1

Download the installer

Press Download for Windows on this page or on the app page. Your browser saves a file called DougHub-Setup.exe, usually in your Downloads folder.

It is about 130 MB, so give it a minute on a slow connection.
2

Keep the file if your browser asks

Edge and Chrome sometimes say a file "isn't commonly downloaded". That is the same reason: it is new. Open the downloads list, press the … menu next to the file, choose Keep, then Show more and Keep anyway.

Chrome: press the arrow beside the warning and choose Keep.
3

Check that it is the real file (optional)

Open PowerShell and run this line. It prints the file's fingerprint. It should match the one on the app page exactly.

Get-FileHash "$env:USERPROFILE\Downloads\DougHub-Setup.exe" -Algorithm SHA256

Expected fingerprint:

23F42B02B3180AF30BB4D28ECBF1682889A8389F8FFD93F17627B4C7DAC49A92
If the letters and numbers are different, delete the file and download it again from this site.
4

Open the installer

Open your Downloads folder and double-click DougHub-Setup.exe. Windows may take a few seconds to scan it before anything appears.

5

Pass SmartScreen

A blue window says "Windows protected your PC". This is SmartScreen asking you to confirm. Do these two things:

1. Press More info, the small link under the message.
2. Press Run anyway, the button that appears.

The publisher shows as "Unknown publisher" because the installer is not signed yet. Press Don't run if you did not download it from this page.
6

Install and open DougHub

Windows may ask "Do you want to allow this app to make changes?" Choose Yes. In the installer pick a folder or keep the default, press Install, then Finish. Open DougHub from the desktop or the Start menu, and log in with your normal account.

No account yet? You can make one inside the app. An email is optional.
Only run files you downloaded from doughub.online. If a different website or a message from someone else offers you "DougHub", do not run it. SmartScreen is there to protect you.

If something goes wrong

I do not see a "Run anyway" button

Press the small More info link first. The button only appears after that. If there is still no button, your PC may be set by a school or work admin to block unknown programs. Ask them for help.

The browser deleted the file

Open the browser's downloads list, find the file and press Keep. If it is gone, press the download button again.

Windows says the file is blocked

Right-click the file, choose Properties, tick Unblock at the bottom if it is there, press OK and open it again.

The fingerprint is different

Delete the file and download it again from this site. If it still does not match, tell us on the Report a problem page and do not run it.

Why does Windows not trust it yet?

SmartScreen trusts programs that many people have already run, or that carry a publisher certificate. DougHub's installer is new, so it asks you first. The app is made by DougHub, and the Privacy Policy explains what it collects.
