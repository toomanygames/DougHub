# Kenney character artwork

DougHub uses the following 2D game-art packs for its collectible animal characters and wardrobe:

- [Animal Pack Remastered](https://kenney.nl/assets/animal-pack-remastered) — animal character sprites
- [Character Pack](https://kenney.nl/assets/character-pack) — modular hair, shirts, pants, and shoes

**License:** Creative Commons Zero (CC0). The artwork is served from the public Kenney asset mirror at [shorepine/kenney](https://github.com/shorepine/kenney), which identifies its Kenney library as CC0. DougHub's character names, rarity tiers, collections, prices, and game integration are original DougHub content.

The website uses the stable raw asset paths in the database catalog. If those paths are ever changed, update the matching `art_path` or `art_url` records in Supabase.
