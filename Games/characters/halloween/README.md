# Halloween character artwork

The Halloween characters are original DougHub SVG compositions built around Kenney Animal Pack Remastered sprites.

- Base animal artwork: [Kenney Animal Pack Remastered](https://kenney.nl/assets/animal-pack-remastered), CC0.
- Costume overlays: original DougHub vector artwork in this folder.
- Space collection artwork: [Kenney Alien UFO Pack](https://kenney.nl/assets/alien-ufo-pack), CC0.

The SVGs preserve the same clean, rounded character presentation as the existing DougHub animal collection.
