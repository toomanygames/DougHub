# DougHub accessory artwork

`sprite.svg` is an original vector sprite sheet created for DougHub. It contains the illustrated hats, glasses, scarves, necklaces, wings, backpacks, effects, and other accessories shown in the shop and character editor.

The modular clothing and hair items in the shop are from Kenney's [Character Pack](https://kenney.nl/assets/character-pack), released under CC0. Animal sprites are from Kenney's [Animal Pack Remastered](https://kenney.nl/assets/animal-pack-remastered), also CC0.
