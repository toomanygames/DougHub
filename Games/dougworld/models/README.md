# DougWorld 3D models

All `.glb` models and their `Textures/` in this folder are unmodified assets by **Kenney** (www.kenney.nl), released under **CC0**, taken from the public Kenney mirror at https://github.com/shorepine/kenney. License text: [LICENSE.txt](./LICENSE.txt).

| Folder | Kenney pack | Used for |
| --- | --- | --- |
| `blocky/` | Blocky Characters | Animated player bodies (idle, walk, sprint, sit, emotes) |
| `mini/` | Mini Characters | Animated player bodies (adds jump and fall) |
| `pets/` | Cube Pets | Animated pets that follow players |
| `nature/` | Nature Kit | Park scenery and buildable models |
| `furniture/` | Furniture Kit | Buildable furniture |

Only the model keys listed in `CHAR_MODELS`, `PET_MODELS` and `BUILD_MODELS` in `../main.js` can be used, including in data sent by other players.
