# DougWorld 3D textures

`proto-*.png` are unmodified textures from **Kenney's Prototype Textures** pack (www.kenney.nl), released under **CC0**, taken from the public Kenney mirror at https://github.com/shorepine/kenney. License text: [LICENSE.txt](./LICENSE.txt).

DougWorld also uses OpenMoji icons from `Games/openmoji` (CC BY-SA 4.0) and the three.js engine (MIT), loaded from jsDelivr.
