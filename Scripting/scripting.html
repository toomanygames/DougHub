Make a game, then publish it

  1. Press Make a game and pick Web or JavaScript.
  2. Edit the starter game, or build it with blocks.
  3. Press Test to play it right in the editor.
  4. Press Publish game. It shows up under Community Games on the Games page.

Good to know

  1. Games run in the browser, so they use Web or JavaScript.
  2. Python and Lua are great for projects you share here.
  3. You can update a published game any time. Players get the new version.
