How Nova learns

It creates follow-up search queries from a topic, gathers results, compares titles against the initial search, and stores useful snippets.

🧠 Persistent memory

Saved facts and research remain in localStorage on this browser, even after you close the page.

✓ Self-review

Nova flags unverified information and keeps links to source pages. Matching results are not proof of truth.

AI connection & automatic learning

This version is installed on DougHub and can research automatically, save lessons, and recall them. For true AI reasoning, it needs a server-side model connection.

Security
Never put an AI provider's secret API key in this page or localStorage. A backend endpoint (for example, a Supabase Edge Function) must keep that secret private.

What is already implemented

Live Wikipedia search · generated follow-up questions · source links · local memory · export/forget controls · basic consistency checks.

What needs a real model

Original AI-generated questions, deeper reasoning across articles, robust fact-checking, and autonomous decisions about what to learn next.

Nova AI is experimental. Always verify important claims using the linked sources.
